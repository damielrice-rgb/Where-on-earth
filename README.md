# Where in the World?

This is a responsive country information website I built as a Frontend Mentor project. I used **HTML, Tailwind CSS, TypeScript, Vite, the REST Countries API, and local JSON data**. The app allows users to search for countries, filter them by region, and click on a country to view more information such as its population, region, capital, languages, borders, and flag. One of the biggest things I learned from this project was how to work with APIs and handle errors when an API request doesn't work as expected. I also learned how to normalize API data so I could use it throughout my application and how to use local JSON data as a fallback. I got more comfortable with TypeScript, Tailwind CSS, responsive design, and organizing my code into separate files. I also learned a lot from troubleshooting issues with CORS, API endpoints, Vite, and TypeScript. Overall, this project helped me understand how the different parts of a frontend application work together and gave me more confidence working with APIs and building responsive websites.
here is the live link to my project: https://where-in-the-world2026.netlify.app/
